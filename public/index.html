Post

Posting klip ke YouTube & TikTok + jadwal upload.

🔗 Sambungan posting

Posting resmi butuh sambungan OAuth per platform (bukan cookies — cookies hanya untuk download). YouTube dulu; TikTok menyusul setelah YouTube stabil.

▶️ YouTubeMemeriksa…

Isi sekali dari Google Cloud (gratis): buat project → aktifkan YouTube Data API v3 → buat OAuth Client ID (Web) dengan Redirect URI persis https://script.dzw.my.id/api/post/oauth/youtube/callback → tempel Client ID + Secret di sini (tersimpan di .env server, tidak pernah ditampilkan lagi).

    🍪 Cookies YouTube (per akun)

    Dipakai download klip akun ini — dan nanti bisa dipakai fitur posting (YouTube/TikTok/dll) dari akun yang sama. Export cookies.txt dari browser yang sudah login YouTube, lalu upload di sini. Tiap akun punya file sendiri, akun lain tidak bisa pakai. Bila akun ini belum upload, download tetap pakai file cookies global lama di PC (tidak diubah).

    💾 Penyimpanan Library

    Lokasi database Script & Video Library (file JSON per akun + video Clipper tetap di folder Clipper).

    Otomatis: Pi → /opt/docker/hermes-vo-library (partisi gede). Linux lain / Windows / macOS / Docker → folder library di sebelah server.js. Lokasi baru langsung aktif, tapi file lama TIDAK dipindahkan otomatis — pindahkan manual folder lama ke lokasi baru kalau mau data lama ikut.

    📣 Notifikasi Telegram (per akun)

    Kirim notif ke Telegram akun ini tiap render Clipper selesai ("🎬 Video sudah jadi!"). Token + Chat ID tersimpan di folder akun ini saja (bukan .env global) dan tidak pernah ditampilkan kembali. Kosongkan keduanya = tidak diubah.
